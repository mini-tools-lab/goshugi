# ご祝儀相場チェッカー 公開パッケージ

GitHub Pages にそのままアップロードして公開するための一式です。すべて単独で動作する静的ファイルで、外部リソース（CDN・外部フォント等）は使っていません。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | ツール本体（関係性・年代・出席の形から相場目安とおすすめ金額を表示） |
| `guide.html` | 解説ページ（相場の考え方・夫婦/欠席の場合・金額のタブーとマナー） |
| `sitemap.xml` | 検索エンジン向けサイトマップ |
| `robots.txt` | クローラー向け設定（sitemap の場所を通知） |
| `README.md` | このファイル |

## データの根拠

ゼクシィ結婚トレンド調査、全日本冠婚葬祭互助協会「婚礼に関するアンケート調査」など公開調査の最多回答額を中心に、複数のマナー資料を照合して目安を作成。金額は一般的な目安であり、地域・家庭の慣習で異なる旨をページ内に明記しています。

## 公開手順（GitHub Pages）

1. GitHub にログインし、新しいリポジトリを作成する（名前は `goshugi`、Public）
2. このフォルダのファイルをすべてリポジトリ直下にアップロードする（`Add file` → `Upload files`）
3. リポジトリの `Settings` → `Pages` を開く
4. `Build and deployment` の Source で `Deploy from a branch` を選び、Branch は `main` / `(root)` にして `Save`
5. 数分待つと `https://mini-tools-lab.github.io/goshugi/` で公開される
